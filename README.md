## Особенности конвертации

- таблицы сохранены как HTML-таблицы внутри Markdown, включая объединённые ячейки;
- иллюстрации вставлены непосредственно в месте их расположения на странице;
- команды и конфигурационные фрагменты оформлены отдельными блоками;
- повторяющиеся колонтитулы и номера страниц убраны, а границы печатных страниц отмечены HTML-комментариями.
