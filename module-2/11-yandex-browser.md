# Яндекс Браузер — HQ-CLI

От root:

```bash
apt-get update
apt-get install -y yandex-browser-stable
```

Если пакет недоступен, установи Яндекс Браузер через Центр приложений.

Запусти браузер из меню под обычным пользователем. Открой `http://web.au-team.irpo` (вход `WEB / P@ssw0rd`) и `http://docker.au-team.irpo`.

В отчет: установленный браузер и скриншот запуска/версии.
