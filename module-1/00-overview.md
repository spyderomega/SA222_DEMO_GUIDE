# Топология и адреса

![Топология](../assets/page-013-img-01.jpeg)

Адреса из примера практикума; используй их согласованно во всех настройках.

| Устройство / сеть | IPv4 | Шлюз |
| --- | --- | --- |
| ISP → провайдер | DHCP | DHCP |
| ISP → HQ-RTR | 172.16.1.1/28 | — |
| ISP → BR-RTR | 172.16.2.1/28 | — |
| HQ-RTR → ISP (`isp`) | 172.16.1.2/28 | 172.16.1.1 |
| HQ-RTR → VLAN 100 (`vl100`) | 192.168.100.1/27 | — |
| HQ-RTR → VLAN 200 (`vl200`) | 192.168.200.1/24 | — |
| HQ-RTR → VLAN 999 (`vl999`) | 192.168.99.1/29 | — |
| BR-RTR → ISP (`isp`) | 172.16.2.2/28 | 172.16.2.1 |
| BR-RTR → BR-SRV (`int1`) | 192.168.0.1/28 | — |
| HQ-SRV | 192.168.100.2/27 | 192.168.100.1 |
| HQ-CLI | DHCP, пример 192.168.200.2/24 | 192.168.200.1 |
| BR-SRV | 192.168.0.2/28 | 192.168.0.1 |
| Туннель HQ / BR | 10.10.10.1/30 / 10.10.10.2/30 | — |

> **Маски:** VLAN 100 — не более 32 адресов (/27); VLAN 200 — не менее 16 (в примере /24); VLAN 999 — не более 8 (/29); BR — не более 16 (/28). Адрес сети и broadcast устройствам не назначай.

Имена: `hq-rtr.au-team.irpo`, `br-rtr.au-team.irpo`, `hq-srv.au-team.irpo`, `hq-cli.au-team.irpo`, `br-srv.au-team.irpo`; ISP — `isp`.

**Отчет:** таблица адресов, настройки коммутации, туннеля, OSPF и его защиты, DHCP. Для пунктов с отчетом — документ с индексом пункта и кратким названием; итоговый файл — `ФамилияУчастникаМодуль1`. Скриншоты должны быть читаемыми.
