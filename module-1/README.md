# Модуль 1 — сетевая инфраструктура

Команды Linux выполняются от root. В EcoRouter вход в настройку: `enable`, затем `configure terminal`; проверки — из привилегированного режима. После изменений сохраняй конфигурацию: `write memory`.

> **Важно:** имена интерфейсов и портов в примерах относятся к исходному стенду. Сверяй их по MAC-адресам. Значения `<...>` замени своими; строки конфигурации записывай в указанный файл.
